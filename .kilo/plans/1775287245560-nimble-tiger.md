# Plan: Rotations-Animation für MetricCard Trend-Badge

## Ziel
Die Rotation-Animation aus dem React-Code-Snippet in MetricCard implementieren:
- Pfeil dreht sich um 180° wenn Trend negativ wird (▲ → ▼)
- Farbwechsel wird animiert (sanfter Übergang)

## React-Code Referenz
```jsx
<MotionArrowUp
  animate={{ rotate: diff > 0 ? 0 : -180 }}
  initial={false}
/>
```

## Implementierungs-Optionen

### Option 1: Canvas-basierte Rotation (Empfohlen)
- **Vorteile**: Echte Rotation möglich, flüssige Animation
- **Nachteile**: Etwas komplexer, muss Canvas pflegen

### Option 2: Frame-basierte Symbol-Animation (Einfacher)
- **Vorteile**: Schnell implementiert
- **Nachteile**: Keine echte Rotation, nur Symbol-Wechsel

## Plan für Option 1 (Canvas-Rotation)

1. **TrendArrow Canvas-Widget erstellen**
   - Lege ein tk.Canvas an für den Pfeil
   - Zeichne Pfeil als Polygon/Linien

2. **Rotations-Animation implementieren**
   - `animate_rotation(target_angle)` Methode
   - Nutze `after()` mit Easing für sanfte Rotation
   - Winkel: 0° (aufwärts/pos), 180° (abwärts/neg)

3. **Color-Transition hinzufügen**
   - Background-Farbe des BADGE animiert sanit überblenden
   - Von Grün (#10B981) zu Rot (#EF4444)

4. **Metriken-Update anpassen**
   - `update_value()` ruft jetzt `animate_rotation()` auf
   - Übergabe von altem und neuem Trend

## Geschätzter Aufwand
- 1 Stunde für Basis-Implementation
- 30 Minuten für Feintuning
