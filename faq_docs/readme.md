# Willkommen bei FinGPT-Ollama!

FinGPT ist eine moderne und fortschrittliche Trading-Plattform, die hochentwickelte KI (via Ollama) mit klassischen MetaTrader 5 Metriken kombiniert. 

Nutzen Sie die Navigation an der Seite, um Antworten auf häufig gestellte Fragen (FAQ) zu den verschiedenen Modulen der App zu erhalten.
